# 🌈 拼音汉字乐园

给小学 **1~6 年级** 孩子的拼音 + 汉字学习小程序：**看汉字、听读音、拼声母韵母、答对有掌声**，可在设置里勾选想学的年级，内置「学 15 分钟 → 强制休息 5 分钟」的护眼机制，还有 **b/p/d/t/q 易混声母专项** 与 **16 个整体认读音节** 的专门练习，并用更接近课本的**手写体**显示拼音。针对 **iPhone 14 / iPhone 14 Pro** 做了专门的移动端适配。

纯静态网页，**零依赖、零构建、可离线使用**。打开 `index.html` 就能玩，也可以直接用 GitHub Pages 在线访问；在 iPhone 的 Safari 里「添加到主屏幕」即可像 App 一样全屏使用。

> 在线地址：https://zhlushanglong.github.io/pinyin-hanzi-kids/ （已开启 GitHub Pages）

## ✨ 功能

### 需求里的四件事

| 要求 | 实现方式 |
| --- | --- |
| 显示、读出汉字并组词，如「路，道路」 | 田字格显示汉字，旁边展示组词、配图、例句；用浏览器中文语音朗读「路，道路」，可随时点「🔊 再听一遍」 |
| 显示声母、韵母和其它干扰拼音供选择 | 拼音四线三格 + 候选卡片。**简单**：1 个声母 + 3 个韵母（主要是声调干扰，如 `p` / `àn` / `án` / `ān`）混排；**困难**：4 个形近声母 + 6 个韵母干扰，分「先找声母 / 再找韵母」两步 |
| 选择正确给予掌声 | Web Audio API 现场合成 34 次拍手的掌声 + 上行「叮咚」音，配合彩纸动画、星星奖励和「答对啦，真棒！」的语音表扬 |
| 汉字按年级分册 | 内置 **1~6 年级共 667 个常用字**，设置里可勾选任意多个年级，首页年级卡片也能一键切换；出题、听音选字、组词、错字复习都只在所选年级范围内进行 |
| 学 15 分钟后锁定、休息 5 分钟 | 累计有效学习时长达标即弹出**全屏不可关闭的休息页**，5 分钟倒计时结束才自动解锁；刷新、重开标签页、清空学习记录都绕不过去 |
| 手机上使用 | 按 iPhone 14 / 14 Pro 屏幕适配：安全区避让、≥44pt 触控目标、底部常驻「开始学习」、首屏看全题目，详见下方「在 iPhone 上使用」 |
| 更好的想法 | 见下 |

### 额外做的小心思

- **年级自由切换**：默认只学一年级（120 字）；设置里可多选 1~6 年级，也有「全选 6 个年级」「只学一年级」快捷键；题面会标出当前字属于几年级，至少保留一个年级。
- **五种玩法**：🧩 拼一拼（主玩法）、👂 听音选字、🍎 组词小达人、🔤 易混声母、📖 整体认读，换着玩不腻。
- **🔤 易混声母专项**：`b / p / d / t / q` 五个长得像、读起来也容易混的声母单独成题，形状口诀贯穿始终，专门增加难度。
- **📖 整体认读音节**：首页可展开「认一认 16 个整体认读音节」点读表（点一下就朗读），配套专属玩法用 45 道例字题练「不用拼、整个记住」。
- **✍️ 手写体拼音**：拼音改用课本式的手写字体（iPhone 的 Chalkboard SE、Windows 的 Comic Sans MS，跨平台上用内嵌 Comic Neue 兜底），带调字母做了 Unicode 分解，不会一个词里混印刷体。
- **难度切换**：顶栏「简单 / 困难」，练习中随时切换，下一题生效。
- **贴近课本的呈现**：拼音**四线三格**、汉字**田字格**（米字虚线），汉字优先用楷体显示。
- **拼音教学细节**：自动提示「小 ü 碰到 j q x 去掉两点还读 ü」等规则；干扰项优先用**同韵不同调**（`ān / án / ǎn / àn`），这正是孩子最容易错的地方。
- **错字复习**：答错不扣分、不催促，只温柔提示「再听一次」，并自动加入错字本；首页「🔁 只练错字」可集中复习。
- **正反馈系统**：每答对得 ⭐、连对纪录、本轮结束生成小小成绩单；进度条让一轮练习有始有终。
- **护眼休息**：默认学 15 分钟强制休息 5 分钟，顶部进度条实时显示「今天已学多久 / 距离休息还有多久」，休息页有倒计时环、远眺提示和每分钟轮换的护眼小动作。
- **家长可调整**：自动朗读开关、音效开关、朗读语速（0.6~1.2 倍）、每轮题数（5 / 10 / 15）、护眼开关与学习时长（10 / 15 / 20 / 30 分钟，需家长算术验证）、一键清空记录。
- **键盘也能玩**：`1~9` 选答案、`空格` 重听、`回车` 下一题。
- **隐私友好**：学习记录只存在本机浏览器 `localStorage`，不联网、不上传、无广告、无第三方脚本。

## 🔤📖 两个专项练习

### 易混声母 `b / p / d / t / q`

孩子最常把这几个字母的方向记反，所以单独做成一个玩法：

| 项目 | 规则 |
| --- | --- |
| 出题范围 | 只从**当前勾选年级**里声母为 `b / p / d / t / q` 的字出题，年级设置依然生效 |
| 题目形式 | 显示汉字、组词并朗读，**声母藏起来**，从 5 个字母里选出正确声母（5 选 1，比普通模式更难） |
| 形状口诀 | 题面只给一行口诀横幅「6 字 b ｜ 反 6 d ｜ 右上 p ｜ 左上 q ｜ 伞把 t」，不直接或间接显示答案 |
| 答完再讲 | 答错后显示该字母的短口诀（如「左下半圆 d d d」），答对后也带一遍正确口诀，先想后学 |

### 16 个整体认读音节

`zhi chi shi ri · zi ci si · yi wu yu · ye yue yuan yin yun ying`

| 项目 | 规则 |
| --- | --- |
| 点读表 | 首页折叠卡片「认一认 16 个整体认读音节」，展开后 16 张卡片，点任意一张即可听读音、看例字 |
| 专属玩法 | 📖 整体认读：显示例字与组词，从 4 个形近音节中选出对应的整体认读音节 |
| 题库 | 16 个音节共 45 道例字题，每字带组词、配图和带调拼音；干扰项优先取形近音节 |
| 不泄题 | 题面不显示音节拼写或「「ying」是整体认读音节」这类提示；答错时才提示「整体认读音节不用拼」 |
| 与拼一拼的关系 | 整体认读音节教学上**不拼读**，所以从「拼一拼」题库中排除，只在专属玩法里练，避免让孩子把 `zhi` 拆成 `zh + i` |

> 专项题库由 `tools/generate_lessons.py` 生成到 `js/lessons.js`：用 `pypinyin` 按组词定音，校验去调后确实属于对应整体认读音节，并处理「一 / 不」变调。

### ✍️ 关于手写体拼音

拼音使用手写字体栈：`Chalkboard SE`（iPhone / iPad）、`Comic Sans MS`（Windows）、`Segoe Print` / `Bradley Hand` 等系统手写体优先，并内嵌 **Comic Neue**（OFL 授权）的 `fonts/pinyin-hand.woff2` 作为跨平台兜底，安卓和未装手写体的设备也能显示一致风格。

手写字体往往缺少 `ǎ`、`ǜ` 这类预组合带调字母，直接显示会掉回印刷体、一个词里混两种字体。因此所有**显示文本**先做 Unicode NFD 分解（`ǎ` → `a` + 组合声调符号），声调由组合符号叠加；而**答案比较值**保持原样（NFC）放在 `data-value` 里，判题完全不受影响。

## 👀 护眼休息怎么工作

| 项目 | 规则 |
| --- | --- |
| 计时范围 | 只累计**练习页且页面可见**的时间；在首页停留、切到后台、看成绩单都不计时 |
| 触发锁定 | 累计达到设定时长（默认 **15 分钟**）立即锁定，家长可改为 10 / 20 / 30 分钟 |
| 休息时间 | 固定 **5 分钟**，倒计时结束自动解锁，回到休息前那一题，不丢进度 |
| 锁定期间 | 全屏遮罩覆盖，点击与键盘（`1~9` / 空格 / 回车）全部失效，朗读与自动下一题也会停掉 |
| 家长验证 | 关闭护眼、修改学习时长、提前结束休息，都要答对一道随机乘法题 |

**为什么刷新也绕不过去**：计时与休息状态存在独立的 `localStorage`（`pyhz_eyecare_v1`），记录累计毫秒、休息截止时间戳、剩余秒数和当天日期。重新加载页面会先读取它，没休息完就继续显示倒计时；打开多个标签页时通过 `storage` 事件同步。倒计时按真实经过时间递减并限制单次最大跨度，避免系统时间被改动时瞬间跳完或卡死。凌晨跨天会自动重新累计。

**家长提前结束**：休息页底部有「家长提前结束休息（需验证）」，答对乘法题即可立刻解锁，用于误触发或需要临时接管的场景。

> 说明：这是纯前端的本地保护，目的是帮孩子养成用眼习惯，**不是不可破解的管控**。清除浏览器站点数据会同时清掉学习记录与休息状态；孩子若主动修改系统时间并刷新，也无法 100% 防住。需要强约束请配合操作系统级的屏幕时间管理。

## 🚀 运行

**方式一：直接打开**

双击 `index.html`（Edge / Chrome / Safari 均可，无需安装任何东西）。

**方式二：本地服务器（推荐，语音更稳定）**

```bash
cd pinyin-hanzi-kids
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

### ☁️ 一键部署到 GitHub（推荐）

仓库自带 `deploy-to-github.mjs`，**零第三方依赖**，一条命令完成「创建仓库 → 推送全部文件 → 开启 GitHub Pages」：

```bash
GITHUB_TOKEN=ghp_xxxxxxxxxxxx node deploy-to-github.mjs
```

Windows PowerShell：

```powershell
$env:GITHUB_TOKEN="ghp_xxxxxxxxxxxx"; node .\deploy-to-github.mjs
```

Token 在 **GitHub → Settings → Developer settings → Personal access tokens** 生成（经典 token 勾选 `repo`；细粒度 token 需要 Contents / Administration / Pages 读写权限）。Token 只用于本机这一次 API 调用，不会写进任何文件。脚本可重复运行，会更新已有仓库；以 `_` 开头的本地测试页不会上传。

**方式三：手动开启 GitHub Pages**

1. 在 GitHub 网页点 **New repository**，仓库名建议 `pinyin-hanzi-kids`，然后把本目录的文件拖进上传界面（或用上面的脚本）；
2. 仓库 → **Settings → Pages**；
3. **Build and deployment** 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`；
4. 保存后等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

> 若作为**项目站点**（路径带仓库名），所有资源都用相对路径引用，无需任何修改。

## 📖 题库说明

共 **667 个常用字**，按 **1~6 年级**分组：一年级 120 / 二年级 104 / 三年级 108 / 四年级 111 / 五年级 120 / 六年级 104。分级依据常用字频与小学各学段的识字难度整理，方便循序渐进，**并非逐字对应某一版教材的识字表**。

- 每字记录 `汉字 / 声母 / 带调韵母 / 组词 / 年级 / 配图`，完整拼音由「声母 + 韵母」自动合成；读音由 `pypinyin` **按组词确定**，多音字（如「长」在「长大」里读 zhǎng）不会读错。
- **三拼音节**按「声母 + 带介音的韵母」两拼法处理（如 `花 huā = h + uā`、`学 xué = x + ué`），题面会提示「介音要读得又轻又短」；**整体认读音节**（zhī、yī、wǔ 等）不进拼一拼题库，改由专属玩法教学；`ü` 的省写规则也有专门提示。
- **零声母字**（如「爱 ài」「安 ān」「二 èr」）没有声母，不适合本应用「选声母」的题型，因此未收录。
- 干扰项由 `js/data.js` 自动生成：优先**同韵不同调**，再补形近韵母家族，最后从题库真实韵母里兜底，保证简单 / 困难模式都能给足选项。
- 专项数据由 `tools/generate_lessons.py` 生成 `js/lessons.js`，包含 16 个整体认读音节（45 道例字题）与 5 个易混声母的口诀；运行时由 `js/app.js` 按年级过滤并组装题目。

### 想加字、改年级

字表在 `tools/generate_data.py` 的 `TABLES` 里，按 `字:组词` 书写，例如把 `花:花朵` 从一年级挪到二年级，或加一行 `棋:下棋`。改完运行：

```bash
pip install pypinyin
python tools/generate_data.py
python tools/generate_lessons.py
```

脚本会重新生成 `js/data.js`（工具函数模板在 `tools/data.template.js`）与 `js/lessons.js`，并自动跳过重复字、零声母字，校验声调与拼音拆分。**运行网页本身不需要 Python 或任何依赖**，上面的命令只在扩充题库时才用。

## 🔊 关于声音

- **朗读**：使用浏览器内置 `SpeechSynthesis`（`zh-CN`）。系统需安装中文语音包，Windows / macOS / iOS / Android 默认都有；首次点击「开始学习」时会解锁浏览器的音频权限。
- **掌声**：不是音频文件，而是用 `Web Audio API` 把白噪声经过带通滤波、随机声像和包络合成的一串「拍手」，因此**完全离线可用**，也省去版权与加载问题。
- 若浏览器不支持中文朗读，程序会给出提示，其余功能不受影响。
